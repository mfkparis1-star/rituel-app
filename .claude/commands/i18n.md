Add a new localized string for: **$ARGUMENTS**

FR is canonical. Translate the text into French, English, and Turkish, then add it to the locale files under `utils/i18n/locales/` (`fr.ts`, `en.ts`, `tr.ts`).

Rules:
- Choose a sensible key following the existing key naming/nesting convention in the locale files. If `$ARGUMENTS` is clearly `key = text` or `namespace.key: text`, use that key.
- Add the **same key** to all three files — maintain exact key parity (TS-enforced). Never add a key to one file only.
- French text is the source of truth; EN and TR are translations of the FR.
- Match the surrounding formatting (quotes, trailing commas, indentation) of each file.
- After editing, run `npx tsc --noEmit` to confirm parity/types still hold.
